# JobMap Iraq - Correct Tech Stack ✅

## Mobile App - FLUTTER ✅

```
Platform: iOS + Android
Framework: Flutter 3.0+
State Management: Riverpod
Maps: Google Maps Flutter
Location: geolocator
Storage: shared_preferences
HTTP: http package

Location: mobile/flutter_app/
```

## Web Dashboard - REACT ✅

```
Framework: React 18
State Management: Redux Toolkit
Routing: React Router
HTTP: Axios
Styling: CSS (basic)

Location: web/dashboard/
```

## Backend - NestJS ✅

```
Framework: NestJS
Language: TypeScript
Database: PostgreSQL
Cache: Redis
Auth: JWT
ORM: TypeORM

Location: backend/
```

## Services

```
PostgreSQL  → localhost:5432
Redis       → localhost:6379
Backend API → localhost:3000
React Web   → localhost:3000 (after build)
Flutter     → Mobile device
```

## NO React Native!

❌ React Native is NOT used
✅ Flutter for mobile only
✅ React for web dashboard only
